EarCopy Assist uses the MuScriptor Python package for model loading and
note-event generation. EarCopy Assist records the official MuScriptor Web UI
as the upstream reference for the initial note-event display, piano roll, and
synchronized source/SoundFont playback design.

EarCopy Assist includes the official MuScriptor small, medium, and large model
weights without modification. The weights are distributed under CC BY-NC 4.0
and the additional conditions published on each official model page. See
`MODEL_NOTICE.txt` for the attribution, license URI, source pages, warranty
disclaimer, and additional-condition summary.
