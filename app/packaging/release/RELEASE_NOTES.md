# EarCopy Assist ${VERSION}

EarCopy AssistのWindows x64用ポータブルパッケージです。ZIPを展開し、
`EarCopyAssist.exe`を起動してください。

ソースコミット: [${SOURCE_COMMIT}](https://github.com/tori128/sheetMusicHelper/tree/${SOURCE_COMMIT})

## ダウンロード

- `EarCopyAssist-${VERSION}-win-x64.zxx`: Windows版分割ZIP
- `EarCopyAssist-${VERSION}-win-x64.zip`: Windows版分割ZIP
- `EarCopyAssist-${VERSION}-muscriptor-small.zip`: MuScriptor smallモデル
- `EarCopyAssist-${VERSION}-muscriptor-medium.zip`: MuScriptor mediumモデル
- `EarCopyAssist-${VERSION}-muscriptor-large.z01`以降: MuScriptor largeモデルの分割ZIP
- `EarCopyAssist-${VERSION}-muscriptor-large.zip`: MuScriptor largeモデルの分割ZIP

`.z01`から始まる全ボリュームと`.zip`を同じフォルダーへ置き、[7-Zip](https://www.7-zip.org/)などの分割ZIP対応ソフトで、最後の`.zip`を開いて展開してください。
